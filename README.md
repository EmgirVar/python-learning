# Python Learning — Автоматизация тестирования

Репозиторий для обучения автоматизации на Python + Playwright + pytest.

## Структура

- `Week_1` — Python основы, функции, списки
- `Week_2` — Словари, JSON, Git
- `Week_3` — ООП, наследование, POM
- `Week_4` — Pytest: фикстуры, параметризация
- `Week_5` — Playwright: UI-автоматизация, селекторы, действия, сортировка
